# Security policy

Report vulnerabilities privately to **security@nitroos.org**. Do not open a public issue or pull request.

Please include:
- the NitroOS version (`winver`) and architecture (64-bit / 32-bit);
- what an attacker can achieve (e.g. privilege escalation, sandbox escape, crash) and from which starting point (unprivileged user, sandboxed process, network);
- steps or a minimal program to reproduce.

We will acknowledge your report, keep you informed while we fix it, and credit you in the release notes if you wish. Fixes are released in the next NitroOS release, or sooner when the impact warrants it.

NitroOS is an unofficial downstream of ReactOS. If the issue also affects upstream ReactOS, we will coordinate with the ReactOS project.
