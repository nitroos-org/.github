**NitroOS is a ReactOS-based, Windows-compatible desktop that runs current 64-bit and 32-bit apps.** An unofficial build, not affiliated with the [ReactOS project](https://reactos.org).

<p align="center"><img alt="Chrome 157 running on NitroOS 2026.11-1" src="https://raw.githubusercontent.com/nitroos-org/releases/main/docs/img/nitro-browser.webp" width="640"></p>

- **Current apps:** Chrome 157, Firefox 159, VS Code 1.145 and PowerShell 7.6 run.
- **32-bit and 64-bit side by side:** 64-bit and 32-bit Firefox at the same time.
- **.NET Framework 4.8** WinForms programs run.
- **Measured against stock ReactOS** (32-bit builds): 134x faster demand-zero page faults, 66x faster copy-on-write faults, 10.6x faster heap (single-threaded tests).

Same task, NitroOS next to ReactOS 0.4.16, with screenshots: **[nitroos.org](https://nitroos.org)** or the [releases README](https://github.com/nitroos-org/releases#screenshots-nitroos-vs-reactos).
